# Dork Plugins

Claude Code plugins by [Dork Labs](https://github.com/dork-labs) — commands, skills, and agents for product development with AI.

## Get Started

```
/plugin marketplace add dork-labs/dork-plugins
```

## Plugins

| Plugin | Version | Description | Install |
|--------|---------|-------------|---------|
| [persona-toolkit](./persona-toolkit/) | 0.1.0 | User personas and journey maps for developer tools and B2B SaaS | `/plugin install persona-toolkit@dork-labs` |

## About

Dork Labs builds open-source tools for autonomous AI development:

- **[DorkOS](https://github.com/dork-labs/dorkos)** — Web interface and API for Claude Code
- **[Loop](https://github.com/dork-labs/loop)** — Autonomous product engine that closes the feedback loop

These plugins package the workflows and methodologies we use to build our own products — now available for any project.
