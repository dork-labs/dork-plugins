# Dork Labs Claude Plugins

A marketplace of Claude Code plugins by [Dork Labs](https://github.com/dork-labs).

## Available Plugins

| Plugin | Version | Description |
|--------|---------|-------------|
| [persona-toolkit](./persona-toolkit/) | 0.1.0 | Build and maintain user personas and journey maps for developer tools |

## Installation

```bash
# Add this marketplace (one-time)
/plugin marketplace add dork-labs/claude-plugins

# Install a plugin
/plugin install persona-toolkit@dork-labs
```
